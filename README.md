## التثبيت لأول مرة

نزّل ملف GENIX-Yemen-Map-Download.exe وشغّله. يحتاج الإنترنت لتحميل الحزمة الأساسية وأحدث برنامج. بعد التثبيت تعمل الخرائط المحلية دون الإنترنت.

## إذا لديك النسخة 1.2.2 والخرائط مثبتة

[ثبّت تحديث الانتقال إلى 1.2.3 مرة واحدة](https://github.com/genixaitech-blip/GENIX-Yemen-Map-Downloads/releases/download/desktop-v1.2.3/GENIX-Yemen-Map-1.2.3-Update-x64.exe) فوق النسخة الحالية. لا تحتاج تنزيل الخرائط مجددًا.

## التحديث بعد ذلك

اتصل بالإنترنت واضغط **تحديث** داخل البرنامج. عند وجود إصدار جديد ينزّله ويتحقق من سلامته، يحفظ أعمالك، يغلق البرنامج، يثبت التحديث ثم يفتحه تلقائيًا. عند عدم وجود تحديث يخبرك أن نسختك محدثة. الخرائط والألوان والرسومات والبيانات المحلية محفوظة على جهازك.
